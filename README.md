## What I've built

**PacketKit** — [packetkit.org](https://packetkit.org)
Legal self-help web app that turns California court-form packets into a guided, step-by-step flow and fills the official PDFs. React on Cloudflare Pages, multilingual (English, Spanish, Chinese, Japanese, Korean, Armenian), Python/FastAPI PDF automation, Stripe billing in progress.

**PestPilot** — client project for Dunbar Pest Control
Back-office web app and public website for a family-owned LA pest control company that ran entirely off a phone. Staff app live, customer database with automated daily backups, updates shipped through a private repo and a one-click update script. *(Client code is private.)*

**REXgoClips** — AI clipping pipeline
Python + Remotion pipeline that uses Gemini to find highlights in long-form video and renders captioned shorts for TikTok, YouTube Shorts and Reels on self-hosted hardware.

**Homelab bots**
Proxmox + Ubuntu Server nodes on 10GbE, Docker and systemd services. Always-on Facebook Marketplace deal scanner (per-category Telegram alerts, CarMax-margin price check) and a Kalshi prediction-market scanner (paper trading, Telegram alerts). I run and evaluate local LLMs alongside cloud APIs.
